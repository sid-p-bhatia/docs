## Searching for Records

You can search for records available in the Parameta Universe using wildcards on the record description e.g.

```java
-- Swaption ATM records
SELECT
  *
FROM
  info.records
WHERE
  description ILIKE '%swaption%'
  AND description ILIKE '%ATM%';

-- Payer/Receiver ATM +100 records
SELECT
  *
FROM
  info.records
WHERE
  description ILIKE '%swaption%'
  AND description ILIKE '%+ 100%';
```
