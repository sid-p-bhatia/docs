## Catalog

Using the Catalog from the left-pane, you can browse your data objects and preview the data (to see data here you need to ensure you have the correct role and warehouse set (from the top-right) e.g. **READER**).

## Worksheets

### Setup

Either select an existing worksheet or create a worksheet by clicking on **Project \> Worksheet** button.

When in the worksheet ensure you have a warehouse selected and the correct role selected e.g. **READER**

<Frame caption="A Snowflake SQL worksheet that can be used to query the data provided.">
  ![](/images/snowflake/img-6.jpg)
</Frame>

You can also select a database for the queries using drop down at the top of the query.
