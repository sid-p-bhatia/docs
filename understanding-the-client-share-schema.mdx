## Sample Queries

### Searching for Records entitled to you

You can search for records using wildcards on the record description e.g.

```java
-- Swaption ATM records
SELECT
  *
FROM
  COMMERCIAL_PACKAGES.SHARE_CLIENT_X.RECORDS
WHERE
  description ILIKE '%swaption%'
  AND description ILIKE '%ATM%';

-- Payer/Receiver ATM +100 records
SELECT
  *
FROM
  COMMERCIAL_PACKAGES.SHARE_CLIENT_X.RECORDS
WHERE
  description ILIKE '%swaption%'
  AND description ILIKE '%+ 100%';
```

<Note>
  **Note:** You can also search for records within the Parameta universe in the [Info Schema](https://parametasolutions.mintlify.app/using-info-schema?_mintlify-live-preview=true#searching-for-records).
</Note>

### Retrieve All records within the data

```java
SELECT 
  * 
FROM 
  COMMERCIAL_PACKAGES.SHARE_CLIENT_X.CLIENTX_IRO
limit 10;
```

### Data for a specific record name

```java
SELECT 
  * 
FROM COMMERCIAL_PACKAGES.SHARE_CLIENT_X.CLIENTX_IRO
WHERE 
  name ='IVSWPGBL40003Y15Y:LDN.BIL.QTE.RTM!IC';
```

### Date range available for a record

```java
SELECT 
  RECORD,
  MIN(ACTIV_DATE) AS EARLIEST_ACTIV_DATE, 
  MAX(ACTIV_DATE) AS LATEST_ACTIV_DATE
FROM 
  COMMERCIAL_PACKAGES.SHARE_CLIENT_X.CLIENTX_IRO
WHERE 
  record IN ('IVSWPGBL40003Y15Y:LDN.BIL.QTE.RTM!IC')
GROUP BY
  RECORD;
```

### Retrieve applicable fields for a record/ field group

```java
SELECT 
  * 
FROM 
  COMMERCIAL_PACKAGES.INFO.FIELD_GROUP
WHERE 
  NAME = 'IVSWR';
```
<Note>
  **Note:** Here 'Field Group' is represented by the first 5 characters of the record name. Refer the [Info schema documentation](https://parametasolutions.mintlify.app/using-info-schema) for more details.
</Note>

## Calling Snap Functions

If requested, we provide snapshots of data via User Defined Functions (UDF), which dynamically snap data based on the provided snap time. The snap provides the latest tick to the requested snap time based on a 24 hour look back period. To call these functions you can provide the following arguments:

```java
table(
  COMMERCIAL_PACKAGES.SHARE_CLIENT_X.ICAP_INTEREST_RATE_DERIVATIVES_LDN_DAY_SNAP_1100(
    to_date('<date_str>'),
    '<regex_record_lookup>',
    '<regex_currency_lookup>'
  )
)
```

### An example with a Field group and Currency pair:

```java
SELECT
  snap_timezone,
  snap_end_ltz,
  snap_end_utc,
  EVENT_TIMESTAMP,
  RECORD,
  ACTIV_DATE "Date of Update",
  ASK "Ask",
  BID "Bid",
  CCY1 "Currency",
  GN_TX20_2 "Settlement Index",
  GN_TXT16_2 "Daycount",
  GN_TXT32_4 "Instrument Description",
  MID_PRICE "Mid",
  PERIOD1 "Tenor",
  TIMACT "Time of Update",
  VALUE_DT1 "Start Date",
  VALUE_DT2 "End Date"
FROM
  TABLE(
    COMMERCIAL_PACKAGES.SHARE_CLIENT_X.ICAP_INTEREST_RATE_DERIVATIVES_LDN_DAY_SNAP_1100(
      TO_DATE('2025-09-11'),
      'IRIRS.*',
      'CHF'
    )
  );
```

### Pulling Snap History

If pulling large quantities of history (particularly snaps) it is usually more efficient to load up the warehouse and pull the data asynchronously 
like below (sample code in python):

```python
from snowflake.snowpark import Session
import pandas as pd
from datetime import datetime, timedelta
import time
# Connection configuration
connection = {
  ...
}
# Create a Snowpark session
session = Session.builder.configs(connection).create()
# Define start and end dates
start_date = datetime(2025, 1, 1)
end_date = datetime(2025, 2, 1)
# Generate a range of dates
date_range = [(start_date + timedelta(days=i)).strftime("%Y-%m-%d") for i in range((end_date - start_date).days + 1)]
# Function to run queries asynchronously
query_list = []
results_df = pd.DataFrame()
for date in date_range:
    print(f"Submitting query for date: {date}")
    sql_cmd = f"""
    SELECT * FROM TABLE(
        COMMERCIAL_PACKAGES.SHARE_DEMO.icap_interest_rate_options_day_snap_1500tok(
            TO_DATE('{date}'), '.*', '.*'
        )
    );
    """
    queryid = session.sql(sql_cmd).collect_nowait().query_id
    async_job = session.create_async_job(queryid)
    query_list.append(async_job)
while len(query_list) > 0:
    for qry_job in query_list:
        if qry_job.is_done():
            print(f"Query {qry_job.query_id} is done.")
            query_df = qry_job.to_df().to_pandas()
            query_df.to_csv(f"data_{qry_job.query_id}.csv", index=False)
            print(f"query_listery {qry_job.query_id} is written.")
            query_list.remove(qry_job)  
    time.sleep(10)
    print(f"Waiting for {len(query_list)} queries to finish...")
# Close the session
session.close()
```
